# PROJECT DESCRIPTION
The goal of this project is to train an AI program how to play the game Super Mariokart for the SNES. This project takes heavy inspiration in its approach from Peter Whidden's project on training an AI how to play Pokemon Red for the Gameboy.

# EXTERNAL RESOURCES
## Extra Resources Needed to Run the Project
A legally obtained ROM of Super Mariokart for the SNES.

The SNES9x emulator is used to run the game.

  Emulator download link: https://www.emulator-zone.com/snes/snes9x

## Resources Used for Research/Reference
